title: HOC withLiquid
description: Higher-order component for wrapping components with glass effects
---

The `withLiquid` [higher-order component (HOC)](https://www.patterns.dev/react/hoc-pattern/) provides an alternative way to apply glass effects to your components. It's useful when you want to permanently attach a glass effect to a specific component.

<Callout type="warn">
  **Safari limitation** — this HOC wraps `LiquidGlass`, which inherits the same constraints:
  SVG distortion filters don't work in Safari (only blur and tint render), and having many
  glass-wrapped components simultaneously causes frame drops in Safari specifically. Chrome
  and Firefox are unaffected by this blur performance issue.
</Callout>

## Basic Usage

Wrap your component with `withLiquid`:

```tsx
import { withLiquid } from "react-glassy";
import "react-glassy/styles.css";

function ProfileCard({ name, avatar }) {
  return (
    <div>
      <img src={avatar} alt={name} />
      <h3>{name}</h3>
    </div>
  );
}

export const GlassProfileCard = withLiquid(ProfileCard, {
  preset: "frost",
  config: { borderRadius: "16px" },
});
```

## Passing Configuration

You can pass glass configuration when creating the HOC:

```tsx
import { withLiquid } from "react-glassy";

const GlassButton = withLiquid(Button, {
  preset: "edge",
  config: {
    blur: "8px",
    specular: false,
  },
});
```

## Complete Example

```tsx
import { withLiquid } from "react-glassy";
import "react-glassy/styles.css";

interface CardProps {
  title: string;
  description: string;
  className?: string;
}

function Card({ title, description, className }: CardProps) {
  return (
    <div className={className}>
      <h2>{title}</h2>
      <p>{description}</p>
    </div>
  );
}

export const GlassCard = withLiquid(Card, {
  preset: "frost",
  config: {
    borderRadius: "24px",
  },
});

function App() {
  return (
    <GlassCard
      title="Glass Card"
      description="This card always has a glass effect"
    />
  );
}
```
